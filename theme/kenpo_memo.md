## 全体の作り方

- 構造エリアは、基本書（芦部型）の目次の並びに合わせた：**憲法総論／人権（総論・各論）／統治／憲法保障**。
- 人権各論は手引きの例どおり **自由権 → 精神的自由・経済的自由・人身の自由** とし、その横に参政権・国務請求権・社会権を並べた。
- 論点は、構造の形が分かる程度の代表例だけ。学説は、手引きに従って**エイリアスにせず**、論点の第2段（子）として立てた（公共の福祉の3説、私人間効力の3説、生存権の3説、正当な補償の2説など）。
- ID の付け方：構造は `kenpo-` で始め、論点は接頭辞なし。同じ言葉で別の学説がある場合（「間接適用説」「二元説」など）は、名前に（私人間効力）（選挙権）を添えて区別した。
- `related` は向きを持たないので、片側にだけ書いた。空の項目（aliases など）は省いている。

## 分け方に迷ったところと、どう決めたか

| 迷ったところ | 決め方 |
|---|---|
| 統治の「裁判所」の章の名前 | 基本書では「裁判所」が多いが、民事訴訟法の「裁判所」（管轄・除斥など）と意味がぶつかる。名前に科目を添える代わりに「**司法**」にした。「裁判所（憲法）」とするほうがよければ変える |
| 違憲審査制・審査基準論の置き場所 | 「憲法訴訟」を構造に立て、親を「憲法保障」と「司法」の両方にした。審査基準（二重の基準論）は人権総論で教える本も多いので、論点の側で人権総論にもぶら下げた |
| 集会・結社の自由 | 21条1項なので「表現の自由」の子にした。精神的自由の直下に並べる本もある |
| 居住・移転の自由 | 人身の自由の面もあるとされるが、22条の並びに合わせて経済的自由だけに置いた |
| 平和主義・国民主権・天皇 | 総論に置く本が多い。国民主権と天皇は統治の原理・機関でもあるので統治も親にした。平和主義は総論だけ |
| 地方自治 | 行政法（地方自治法）と共有する見込みなので、ID を `chihou-jichi`（科目の接頭辞なし）にした |
| 公共の福祉 | 手引きの例に合わせ、論点の第1段「公共の福祉」の子として3説を立てた。手引きでは「関連でつなぐ」としているが、説は論点の子にするほうが一覧しやすいと考えた（下の「人が決めるべき点」1） |
| 人身の自由 | 31条（適正手続）と33〜39条（被疑者・被告人の権利）の2つに分けた。刑事訴訟法を作るときに、刑訴側の構造からも親にする見込み |

## 複数の親にしたもの（17件）

- 包括的基本権：人権総論＋人権各論。法の下の平等と同じく、総論と各論の間にある

- 政教分離：信教の自由＋財政。20条と89条にまたがる
- 憲法訴訟：憲法保障＋司法。違憲審査制はどちらの章でも扱われる

## エイリアスにしなかったもの（手引き4の規則による）

- 公共の福祉 ≠「人権相互の矛盾・衝突を調整する原理」（一元的内在制約説という一つの立場）
- 特別な法律関係における人権 ≠「特別権力関係」（特別権力関係論という一つの理論。別の論点として子に立てた）
- 法の下の平等 ≠「平等権」「平等原則」（14条を権利と見るか原則と見るかの議論があるため）
- プライバシー権 ≠「自己情報コントロール権」（プライバシー権の一つの捉え方。子の論点にした）
- 一事不再理 ≠「二重の危険」「二重処罰の禁止」（39条の読み方の違い。別の論点にして関連でつないだ）
- 自己負罪拒否特権 ≠「黙秘権」（保障の範囲が違う。刑訴を作るときに関連でつなぐ予定）

## 人が決めるべきだと思う点

1. ~~**学説を論点ツリーの子にするか、関連だけでつなぐか。**~~ → 決まった（2026-10-21）：子にして「学説」の種類でまとめ、段に数えない。 素案では子にした（例：公共の福祉 > 一元的内在制約説）。手引きの例では「関連」でつないでいる。子にすると、論点の段が1つ減る（学説だけで第2段を使う）。
2. **エイリアスにしてよいか、確認が要るもの**
   - 国務請求権 ←「受益権」（同じ分類の古い呼び名と判断した）
   - 議員定数不均衡 ←「一票の較差」「一票の格差」（厳密には「較差」は不均衡の度合いを指す言葉）

   - 統治行為 ←「統治行為論」（概念と理論の違い）
3. **「司法」という名前**（上の表を参照）。「裁判所（憲法）」にするか。
4. **「憲法保障」を構造の最上段に置くか。** 憲法改正と憲法訴訟をまとめる枠として立てたが、統治の下に入れる本もある。
5. **令状主義・適正手続の扱い。** 憲法では論点にしたが、刑事訴訟法では構造エリアにしたほうがよいかもしれない。科目をまたぐテーマを、どちらの科目の構造に置くかの決まりがあるとよい。
6. **科目の上に「公法・民事法・刑事法」のような段を置くか。** 今は「憲法」を最上位（親なし）にしている。
7. **判例名を論点にするか。** 素案では判例名（森林法判決など）はテーマにしていない。判例はタグではなく問題オブジェクトの別の項目として持つほうがよいと考える。
