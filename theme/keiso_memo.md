## この科目で試したこと：next（次の段階）

手続法は樹形図だけでは流れが表せないので、構造エリアに **`next`（次の段階）** を試しに足した。

- `next` は手続の上で次に進む段階を指す。向きがあり、分かれ道は複数書く。
- `next` を張るのは構造エリアどうしだけにした（チェックスクリプトでも確かめる）。
- タグ付けと集計は今までどおり親子関係（樹形図）で行う。`next` は流れを見るためだけのもの。
- 憲法・刑法には `next` を書いていない。書かなくても規則とぶつからない。

ページでは、樹形図の上に「手続の流れ」として2つの図を出す。
- **大きな流れ**：捜査 → 公訴 → 公判（または特別な手続）→ 裁判 → 上訴 → 非常救済手続
- **細かい流れ**：逮捕 → 勾留 → 公訴の提起 → 公判準備 → 冒頭手続 → 証拠調べ手続 → 論告・弁論 → 判決 → 控訴 → 上告 → 裁判の効力 → 再審・非常上告。破棄差戻しや再審で公判手続に戻る矢印もある

テーマを選ぶと、詳細の欄に「前の段階」「次の段階」も出る。

## 構造エリアの作り方

1. **手続の段階**（`next` でつなぐ）：捜査／公訴／特別な手続／公判／裁判／上訴／非常救済手続。基本書の目次がほぼこの順番。
2. **流れに乗らない枠**（`next` なし）：刑事訴訟の基本原則／訴訟主体／証拠。
   - 証拠は公判の証拠調べで使う決まりだが、基本書で独立した大きな章になっているので段階とは別の枠にした。「証拠調べ手続」とは関連でつないだ。

## 複数の親にしたもの

**構造エリア（3件）**
- 被疑者・被告人の防御：捜査＋公判（弁護人・接見・黙秘権は両方の段階で問題になる）
- 訴因：公訴＋公判（起訴状で示し、公判で変更が問題になる）
- 違法収集証拠：証拠＋捜査（証拠能力の問題だが、もとは捜査の違法）

**論点の第1段（10件）**
- 国選弁護：訴訟主体＋被疑者・被告人の防御
- 任意同行と実質的逮捕：任意捜査と強制捜査＋逮捕
- 逮捕前置主義・事件単位の原則・別件逮捕・勾留・再逮捕・再勾留：逮捕＋勾留
- 保釈：勾留＋公判
- 逮捕に伴う捜索・差押え：捜索・差押え＋逮捕
- 黙秘権：被疑者・被告人の防御＋取調べ
- 一罪の一部起訴：公訴＋訴因

## 憲法とのつながり（関連）

- 令状主義（憲法の論点）↔ 強制処分の意義、令状による捜索・差押え、逮捕に伴う捜索・差押え
- 自己負罪拒否特権（憲法）↔ 黙秘権、自白法則
- 一事不再理（憲法）↔ 一事不再理効

令状主義は刑訴では大きなテーマなので構造エリアに立てたかったが、すでに憲法側で論点として立てているので、刑訴では立てずに関連でつないだ。

## 分け方に迷ったところ

| 迷ったところ | 決め方 |
|---|---|
| 勾留の置き場所 | 被告人の勾留（起訴後）もあるが、被疑者の勾留が中心なので捜査の下に置いた。保釈は公判も親にした |
| 不起訴 | 手続がそこで終わる道なので、段階としては立てていない |
| 抗告 | 判決ではなく決定・命令への不服申立てなので、判決からの流れに乗せていない |
| 「裁判」「判決」「裁判の効力」「上訴」「不利益変更禁止」「自白」 | 民事訴訟法や憲法と言葉がぶつかるので、科目名を添えた |
| 当事者主義・自由心証主義 | 民事訴訟法にもある。意味の重なりが大きいが、とりあえず科目名を添えて分けた |

## エイリアス

- エイリアスにしたもの：刑事訴訟法 ← 刑訴法・刑訴、検察官面前調書 ← 検面調書・2号書面、違法収集証拠排除法則 ← 排除法則、「疑わしきは被告人の利益に」← 利益原則
- 人の確認が必要なもの：伝聞証拠 ← 伝聞法則、取調べの録音・録画 ← 取調べの可視化
- エイリアスにしなかったもの：起訴状一本主義 ≠ 予断排除の原則（予断排除のほうが広い）、黙秘権 ≠ 自己負罪拒否特権（保障の範囲が違う）

## 人が決めるべきだと思う点

1. **`next` を手引きの規則に正式に足すか。** 足すなら、民事訴訟法でも同じように使う。
2. **流れ図の細かさ。** 今は「公判手続の中の段階」まで流れにした。細かすぎるか、もっと細かく（勾留延長・起訴前の段階など）するか。
3. **令状主義を、憲法と刑訴のどちらの構造に置くか。** 今は憲法の論点。科目をまたぐ大きなテーマの置き場所の決まりがほしい。
4. **当事者主義・自由心証主義のように、民訴と刑訴で重なる原則を1つのテーマにするか、科目ごとに分けるか。**
