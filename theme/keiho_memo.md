## 全体の作り方

- 構造エリアは、基本書の目次の並びに合わせて、**刑法総論**と**刑法各論**に分けた。
  - 総論：刑法の基礎（罪刑法定主義・適用範囲）／構成要件／違法性／責任／未遂犯／共犯／罪数／刑罰
  - 各論：個人的法益・社会的法益・国家的法益に対する罪の3つに分け、その下に罪の種類を置いた
- 財産犯は出題が多いので、窃盗罪・強盗罪・詐欺罪などの罪ごとに構造の枠を立てた。
- 学説は、憲法と同じく論点の第2段（子）として立てた（因果関係の判断基準、不能犯、背任罪の本質、住居侵入罪の保護法益など）。
- 憲法のテーマとつながるもの（刑罰法規の明確性、名誉毀損罪の真実性の証明、わいせつの概念）は、刑法の側に「関連」を書いた。

## 同じ言葉が科目で違う意味になるもの（手引き6）

民法などと言葉がぶつかるものは、名前に「（刑法）」を添えた：**因果関係・故意・錯誤・過失・違法性・責任・正当防衛・緊急避難**。

正当防衛・緊急避難は、はじめは刑法での使い方が中心なので添えていなかったが、「ぶつかる言葉は全部の科目で添える」と決まった（2026-10-21）ので添えた。

## 分け方に迷ったところと、どう決めたか

| 迷ったところ | 決め方 |
|---|---|
| 故意・過失の位置 | 構成要件の要素とみるか、責任の要素とみるかで分かれる。構造エリアで両方を親にした |
| 錯誤の位置 | 構造としては故意の下に置いた。違法性の錯誤だけは責任の問題でもあるので、論点の側で責任にもぶら下げた |
| 法定的符合説・具体的符合説 | 客体の錯誤でも問題になるが、論点の第2・3段は親を1つしか持てない。争いが目立つ方法の錯誤の下（第3段）に置いた |
| 危険の現実化 | 学説ではなく判例の判断の枠組みだが、因果関係の判断基準として説と並べた |
| 財産犯の保護法益・刑法上の占有・不法領得の意思・親族相盗例 | 窃盗罪で問われることが多いが、財産犯全体の問題なので「財産に対する罪」の直下に置いた |
| 住居を侵す罪 | 自由に対する罪に入れる本もある。保護法益の争いがあるので独立させた |
| 内乱・外患など | 短答でほとんど問われないので、今回は立てていない |

## エイリアスにしたもの・しなかったもの

**エイリアスにしたもの**（同じものの別の呼び名とみた）
- 幇助犯 ← 従犯（62条の条文の呼び名）
- 方法の錯誤 ← 打撃の錯誤
- 中止犯 ← 中止未遂
- 共犯関係からの離脱 ← 共犯からの離脱
- 財産に対する罪 ← 財産犯
- 欺罔行為 ← 欺く行為

**人の確認が必要なもの**
- 違法性の錯誤 ← 法律の錯誤（同じ意味で使う本が多いが、区別する立場もある）
- 遡及処罰の禁止 ← 事後法の禁止

**エイリアスにしなかったもの**
- 構成要件 ≠ 構成要件該当性（枠と、それに当たるかという判断は別）
- 違法性の意識 ≠ 違法性の意識の可能性（どちらを責任の要件とみるかが学説の対立点）
- 拘禁刑 ≠ 懲役・禁錮（2025年6月から拘禁刑にまとめられた。古い制度なので言い換えではない）
